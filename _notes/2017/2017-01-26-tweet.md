It was great to have you at the data vis meetup, Beni Buess! Loved the remark that tools should have "as few options as possible".

---

Here are some of his slides in text form:

Two classes of challenges: **people** and **technology**

Training people on tools needs **patience** and **tenacity**.
It takes **time** away from developing the next big thing.

Journalists need to learn how to produce something that **looks right**.
We do not get born as graphic editors.

Tools should make it as easy as possible to create something good-looking and as hard as possible to create something wrong.

**Q wants to be easy**: 

- One stop shop for everything not text nor image for journalists
- Tools have as few options as possible
- Tools behave similar
- Embedding a thing in an article works the same for every tool
